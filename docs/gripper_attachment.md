# 기존 좌우 핑거에 수제 사과용 어댑터 장착

설정은 `configs/gripper_attachment.yaml`, 변환은 `aple/execution/gripper_geometry.py`에 있다.
사진의 네 숫자는 동그라미로 표시한 점 사이 거리이며 전부 **mm**다.

| 치수선 식별자 | 사진 거리 (mm) | SI 변환 (m) |
| --- | ---: | ---: |
| D1 | 48.144 | 0.048144 |
| D2 | 48.464 | 0.048464 |
| D3 | 71.76 | 0.07176 |
| D4 | 79.76 | 0.07976 |

D1–D4는 위 표의 숫자로 구분하는 참조 식별자다. 이 거리만으로 플랜지에서 파지점까지의 XYZ 벡터나 외형 두께를 확정할 수 없다. 배경 격자 숫자는 부품 치수로 사용하지 않는다.

[AgileX PiPER 사용자 매뉴얼 V1.0, 9쪽](https://cdn.shopify.com/s/files/1/0673/6848/5000/files/AgileX_PIPER_Product_User_Manual.pdf?v=1782228874#page=9)은 선택형 기본 그리퍼의 개폐 거리를 0–100 mm로 제시한다. 실제 장착품의 모델과 Studio 캘리브레이션을 확인해야 한다. 새 접촉면의 개폐 간격이나 Studio raw 명령 범위를 이 사양으로 덮어쓰지 않는다.

## 장착 기하 입력

현재 `installed: false`이며 장착 기하는 `null`이다. 조립 CAD 또는 장착 실측으로 아래를 채운 뒤 활성화한다.

- `tcp_offset_mm`: 플랜지 원점에서 고정 파지 기준점까지, 플랜지 좌표계의 [x,y,z]. 기존 핑거와 어댑터를 모두 포함한다. 현재 구현은 TCP 축과 플랜지 축이 같은 이동 보정만 지원하므로 `tcp_axes_match_flange: true` 확인이 필요하다.
- `contact_width_range_mm`: Studio 정규화 명령 0과 100에서 새 접촉면 사이 거리. 전 구간에서 선형 대응하는지 확인한다. 비선형이면 보정표 구현이 먼저 필요하다.
- `finger_thickness_mm`, `finger_width_mm`: 패드를 포함한 핑거 외형의 닫힘 방향 두께와 수직 방향 폭.
- `grasp_height_offset_mm`: 사과 중심 기준 파지 높이. 한 값이 모든 크기 구간에 적용된다. 사과 시험에서 조정할 수 있지만 TCP 기하와 별개다.
- `collision_spheres_flange_mm`: 모든 개폐 상태의 추가 어댑터를 보수적으로 덮는 구들의 플랜지 좌표 중심과 반지름. CAD로 범위를 계산하거나 실측한다.

활성화하면 IK/FK가 같은 TCP 보정을 사용하고, HAL·명령 게이트가 새 접촉면 간격을 사용한다. M1 파지 후보 생성에는 새 핑거 두께·폭이 전달된다. 판정 가능한 사과 크기는 기존 크기 범위와 접촉면 개폐 범위의 교집합으로 제한된다. 궤적 검사는 추가 구를 플랜지 자세로 변환해 바닥과 정적 장애물을 검사한다. 샘플링 검사이며 자기 충돌이나 동적 사과 충돌을 보증하지 않는다.

`installed: true`인데 필수 값이 빠지면 설정을 거부한다. 사진 거리나 기본 사양에서 미확정 장착 값을 추측하지 않는다. 기존 가상 셀은 `configs/simulation/piper.yaml`에서 어댑터를 비활성화하므로 새 어댑터의 검증 결과로 해석하면 안 된다.

## 장치 없이 확인

```bash
python tools/gripper_setup.py          # 사진 거리와 장착 설정 상태
python tools/gripper_setup.py --check  # 미활성/불완전이면 종료 코드 1
```

이 도구는 로봇에 접속하거나 움직이지 않는다. 장착 후 설정을 채워도 실제 실행의 기존 안전 차단은 유지된다.
