# 시뮬레이션 속도 탐색과 촬영 조건

## 현재 실행

```bash
cd /mnt/extra/aple-pac2026
~/.venvs/piper-daemons/bin/python3 tools/run_in_hand_simulation.py --optimize --seed 42
```

영상이 필요하면 `MUJOCO_GL=egl`과 `--video`를 추가한다. 현재 검증은 영상 없는
오프라인 접촉 물리 시험이다. 이번 속도로 Studio 웹 전체 재생 시간을 측정한 결과는 아니다.
기존 웹 재생기는 성공한 결과 폴더에 `tools/replay_in_hand_studio.py`를 사용한다.

현재 기본값은 `configs/simulation/in_hand_speed_selected.yaml` 및
`configs/simulation/in_hand_speed_search_scene.yaml`이다. 실제 실행 설정은 변경하지 않았다.
이전 옆 회전·속도 개선 결과, 영상, 프로파일은 보존했다.

```bash
# 이전 빠른 후보와 원래 전체 바닥 장면으로 복귀
~/.venvs/piper-daemons/bin/python3 tools/run_in_hand_simulation.py --optimize --seed 42 --optimization-config configs/simulation/in_hand_fast.yaml --scene-config configs/simulation/in_hand_full_floor.yaml

~/.venvs/piper-daemons/bin/python3 tools/search_simulation_speed.py --multipliers 16 8 6 4 3 2 1 --seeds 42 7 13 99 2026
```

## 촬영은 시간 주기가 아니라 자세 도착 기준

`aple/hal/piper_motion.py`의 `inspect_views`는 각 목표 자세 이동을 끝내고
안정화 시간을 기다린 다음 `capture_in_hand`를 호출한다. 기본 실기 설정의
`configs/varieties.yaml`에는 `settle_time_s: 0.3`이 있다.
최적화 시뮬레이션은 그 sleep 대신 촬영 직전에 물리를 0.06초 진행한다.
네 검사 각도는 -100/-35/+35/+100도이고 각 자세마다 한 장이다.
사진 간격은 회전·목표 추종 시간에 따라 달라진다. 0.06초마다 연속 촬영하는 방식이 아니다.
뷰별 미끄러짐 검사와 누적·재판정 기준은 그대로다.

현재 합성 RGB-D는 모션 블러와 실제 카메라 노출·프레임 수신 지연을 모델링하지 않는다.
지름과 질량이 맞아도 실기에서 이 촬영 대기나 운반 속도를 그대로 써도 된다는 근거는 아니다.

가상 Piper J6 범위는 -120~+120도(`configs/simulation/piper.yaml`)라서
같은 검사 자세에서 손목만 한 방향으로 360도 연속 회전할 수 없다.
현재 각도 순서는 증가 방향이다. 첫 각도 이동과 검사 후 적재 자세 복귀가 왕복처럼 보인다.
다른 관절과 TCP 위치를 함께 바꾸는 다면 경로는 별도 문제이며, 폐기한 위아래 회전 계획을 복원하지 않았다.

## 속도 외에 해결한 시험 조건

원래 장면의 REJECT 상자는 한 칸이다. 현재 곡면 그리퍼로 세 사과가 모두
관측 불확실성에 의해 REJECT가 되면 두 번째 사과에서 공간이 없어 적재를 거부한다.
판정 기준을 바꾸는 대신 별도 시험 장면의 REJECT를 2×2칸으로 늘렸다.
원래 상자 설정/배치는 덮어쓰지 않았다. 큰 상자를 먼저 샘플링하고 집게가 들어갈
정적 공간을 검사한다. 이 조건은 실행 전의 장면 생성 제약이며 실행에 실패한 seed를
성공할 때까지 다시 돌리거나 제외하지 않는다. 배치 시도 수와 실패 결과도 기록한다.

상자 진입 중 Cartesian 자세 보간의 중간 자세에서 IK가 실패하는 문제가 있었다.
별도 후보는 목표 hover까지의 관절 경로를 먼저 계획하고 기존 관절/구간 안전 검사와
별도 MuJoCo 상태의 외부 물체 접촉 검사를 통과한 경로만 실행한다.
이후 마지막 하강은 기존 감속 경로를 사용한다. IK 수치 실패에는 가까운 시작값을
최대 두 번 시험하며 물리 관절 상태는 바꾸지 않는다. 모든 재계산과 실패를 기록한다.

## 검증 결과와 최대 속도의 의미

선택 후보는 기존 빠른 후보의 보간 속도 설정에 공통 배율 16을 적용한 것이다.
빈손/파지/검사 목표 보간 속도는 각각 28.8/8.8/5.6 rad/s이다.
이는 실제 관절의 달성 속도나 제조사 최고속도가 아니다. 내부 물리 모터의 추종 속도와
각 목표의 최소 실행 시간 0.02초에 의해 제한된다.
마지막 3cm의 절대 관절 속도 상한은 기존과 같은 0.07 rad/s다.
그리퍼 힘, 사과 질량·크기, 물리 timestep, 미끄러짐 한계, 4장 촬영을 유지했다.

총 5개 장면/15개 사과가 집기·검사 4장·기존 M2 재판정·목표 상자 안착·복귀를 통과했고
미끄러짐은 0회였다. 성공 기준은 이 전체 동작이며 색상 정확도 100%를 뜻하지 않는다.
16은 시험 범위에서 처리 시간이 포화된 설정이다. 32로 올려도 더 빨라지지 않았으므로
무한히 높은 명령값을 최대 속도라고 표시하지 않는다. 모든 배치/실기 성공률 보장이 아니다.

`003545`(6), `003544`(16), `003742`(32), `003743`(추가 배치).
