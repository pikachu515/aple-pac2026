# XYZ를 움직이는 독립 관측 실험

**보관용 실험:** 사용자 결정으로 위아래 회전 계획을 폐지했다.
현재 기본 시뮬레이션은 기존 옆 회전으로 복귀했다. 이 폴더와 영상은
비교 기록을 보존하기 위한 것이며 현재 실행 계획이 아니다.

기존 고정 중심 시뮬레이션을 보존하면서, 사과를 든 채로 6개 관절과
XYZ 위치를 바꿔 더 많은 표면을 촬영한다. 실제 로봇 연결은 하지 않는다.
Piper Studio의 기존 서비스와 화면도 바꾸지 않고, 별도의 MuJoCo 세계에서
실행하고 MP4를 저장한다. 실기 실행 코드에 연결된 기능이 아니다.

## 실행

저장소 루트에서 실행한다. 현재 `.venv`는 준비되어 있다.

```bash
# 영상 없이 사과 1개 검사·적재
experiments/free_inspection/.venv/bin/python3 \
  experiments/free_inspection/run.py --quick --seed 42

# 동일 경로를 옆에서 보는 영상으로 기록
MUJOCO_GL=egl experiments/free_inspection/.venv/bin/python3 \
  experiments/free_inspection/run.py --seed 42 --video \
  --output logs/free-inspection-video

# 별도 실험의 검증
experiments/free_inspection/.venv/bin/python3 -m pytest \
  experiments/free_inspection/test_search.py -q
```

출력은 `logs/.../seed-42/`에 저장한다. 같은 이름이 있으면 `-2`, `-3`을
붙이며 이전 결과를 덮어쓰지 않는다. 영상은 `side.mp4`, 측정은
`report.json`, `timings.csv`, 경로는 `trace.json`에 있다. 사진·영상·로그와
가상환경은 git에 포함하지 않는다.

Python 가상환경은 이 폴더 안에 따로 만들었다. 설치된 Studio 의존성은
`/home/seo/.venvs/piper-daemons/lib/python3.10/site-packages`에서 읽어 쓴다.
원래 가상환경을 변경하지 않지만, 의존성까지 완전히 복제한 환경은 아니다.
다른 컴퓨터에서는 Studio 의존성이 설치된 Python으로 환경을 만들고
그 환경의 `site-packages`를 새 환경의 `.pth`에 연결해야 한다.

## 검사 경로와 제한

- `search.yaml`: 관절 후보(rad), 최대 12뷰, 예측 관측 목표 85%, 여유 거리,
  영상 해상도와 타임아웃을 관리한다. 첫 5개 관절의 3,780개 조합을 만들고,
  6번 관절은 두 핑거를 잇는 축이 수평이 되도록 계산한다.
- `scene.yaml`: 기존 전체 바닥 카메라 장면을 복사한 독립 설정이다.
  카메라는 높이 1.2m, 화각 55도이며, 검사 시작·복귀 지점은 맵 중앙이다.
  검사 중에는 이 지점을 벗어나 XYZ와 자세를 변경한다.
- `optimization.yaml`: 기존 시뮬레이션 최적화 설정의 독립 복사본이다.
- 사과는 물리 접촉으로 집고 옮긴다. 이동 중 실제 사과를 순간이동하거나
  고정하지 않는다. 가상의 표면 가시성 예측에만 별도 `MjData`를 사용한다.
- 불투명 핑거와 팔의 가림을 카메라 광선으로 계산하고, 색상 정답을 경로
  선택에 사용하지 않는다. 실제 촬영을 기존 판정 모듈에 넘겨 재판정한다.
- 관절 범위, 작업 영역, 기존 경로 검사와 장면 충돌 검사를 유지한다.
  손에 든 사과가 바닥·다른 사과·상자에 접근하는지도 별도로 검사한다.
  복귀는 검증된 직행 경로를 우선 사용하고, 불가능하면 방문 경로를 되짚는다.
- 물리적으로 닿지 않는 높이나 카메라 밖으로 무한히 뻗는 자세는 제외한다.
  전체 관절 공간의 전역 최적해를 보장하는 탐색은 아니다.

수제 그리퍼 사진의 48.144 / 48.464 / 71.76 / 79.76은 모두 **mm 단위의
표시된 두 점 사이 거리**다. 이 숫자를 임의로 TCP 길이나 직경으로 바꾸지
않았다. 현재 접촉 패드·마찰·TCP와 불투명 표면은 기존 가정 모델을 그대로
쓴다. 실측 CAD·장착 위치·그립력이 반영된 실기 검증 결과는 아니다.

영상 저장을 포함한 컴퓨터 실행 시간은 198.1초이고 MP4는 약 131초다.
관측 면을 늘리는 실험이며, 대회 처리 속도까지 최적화한 경로는 아니다.
예측 관측과 실제 촬영 관측은 구별해야 한다.

## 원래 시뮬레이션으로 돌아가기

이 실험은 별도 프로세스이므로 원래 서비스의 복원 작업이 필요 없다.
Piper Studio 웹 화면도 기존 시뮬레이션을 계속 보여 준다.
기존 고정 중심 CLI를 다시 실행하려면 다음을 사용한다.

```bash
/home/seo/.venvs/piper-daemons/bin/python3 tools/run_in_hand_simulation.py \
  --quick --seed 42 --optimize \
  --scene-config configs/simulation/in_hand_full_floor.yaml
```

`baseline_manifest.json`에는 이 실험 시작 시 기존 `aple`, `configs`,
`tools` 파일 101개의 SHA256을 기록했다. 실험 후 원본이 유지됐는지
확인하기 위한 스냅샷이다. 향후 정상적인 다른 작업으로 원본을 변경하면
해시가 달라지므로 영구 회귀 테스트로 사용하지 않는다.
